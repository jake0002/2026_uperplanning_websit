오스템임플란트 치과 소프트웨어 UX리서치 사례: 현직 치과의사 사용성 테스트에서 UI/UX 개선까지

현직 치과의사 6명과의 사용성 테스트(UT)로 검증한 오스템임플란트 치과 의료용 소프트웨어 UX 사례입니다. UX디자인 에이전시 슈퍼플래닝이 리서치 결과를 UX기획·UI/UX디자인 개선까지 직접 연결했습니다.

"리뉴얼 버전 출시 전, 사용자의 관점에서 UX디자인과 신규 기능을 검증하고 싶습니다."
오스템임플란트 UI/UX개선 프로젝트는 고객사의 이 요청에서 출발했습니다.
슈퍼플래닝은 UX리서처·UX기획자·UX컨설턴트 6명으로 프로젝트팀을 구성해,
약 3개월간 조사 설계부터 개선안, 화면설계서까지 하나의 흐름으로 수행했습니다.
사용성 테스트에서 도출된 문제는 화면 전체의 콘텐츠 위계 재설계로 이어졌으며,
개선 전·후 비교 평가에서 사용성 향상이 확인되었습니다.

프로젝트 속성×
프로젝트오스템임플란트 치과 의료용 소프트웨어 UX리서치 · UI/UX 개선 컨설팅
고객사오스템임플란트
플랫폼치과 진료실용 소프트웨어 (PC 설치형 · 웹 · 태블릿)
수행사슈퍼플래닝 (UX디자인 에이전시)
수행 범위UX리서치 · UX기획 · UI/UX디자인 개선 컨설팅
기간약 3개월
투입 인력6명 (UX리서처 3명 · UX기획자 2명 · UX컨설턴트 1명)
참석자현직 치과의사 6명 (기존 사용 · 이탈 · 미사용 고객)
조사 방식1:1 미션 기반 사용성 테스트(미션 5개) + 휴리스틱 기반 정량평가
장소서울 강남구 논현동 UX리서치 전문 Lab실 (미러룸)
핵심 목표리뉴얼 UI/UX·신규 기능 출시 전 검증, 기존 사용자 불편 확인

이 사례의 핵심은 무엇인가요?

  • 검증 대상 — 치과 진료실에서 사용하는 의료용 소프트웨어의 리뉴얼 버전입니다.
  • 참석자 — 기존 사용 고객, 이탈 고객, 미사용 고객으로 구분한 현직 치과의사 6명입니다.
  • 방법 — 미션 5개 기반 1:1 사용성 테스트와 휴리스틱 기반 정량평가를 병행했습니다.
  • 발견 — 진료 현장과 다른 용어, 찾기 어려운 주요 차팅 메뉴, 약한 시각적 위계가 확인되었습니다.
  • 반영 — 리서치 결과를 개선안과 화면설계서로 구체화하고, 콘텐츠 강약 체계를 재설계했습니다.
  • 성과 — 개선 전·후 비교 평가에서 사용성 향상이 확인되었습니다.
UX리서치의 가치는 보고서가 아니라, 개선된 화면에서 증명됩니다.

왜 출시 전에 현직 치과의사와 사용성 테스트를 진행했나요?

전문가용 소프트웨어는 내부 검토만으로 현장의 문제를 찾기 어렵기 때문입니다.
치과 진료실 소프트웨어의 사용자는 진료 흐름 안에서 프로그램을 다루는 전문가이며,
이들이 쓰는 용어와 작업 순서는 내부 기획자나 일반 사용자로는 재현하기 어렵습니다.

프로젝트의 목표는 두 가지로 정의했습니다.

  1. 출시 전 검증 — 리뉴얼된 UI/UX디자인과 신규 기능이 실제 진료 환경에서 문제없이 쓰이는지 확인합니다.
  2. 기존 불편 진단 — 이전 버전 사용자가 겪어 온 불편을 찾아 리뉴얼 설계에 반영합니다.

의사 참석자는 어떤 기준으로 선정하고 섭외했나요?

페르소나와 유저 저니맵으로 스크리닝 조건을 먼저 확정하고, 사용 경험에 따라 세 그룹으로 나눴습니다.
바쁜 전문직일수록 조사 목적에 정확히 맞는 참석자를 고르는 것이 결과의 품질을 좌우합니다.

표 1. 참석자 그룹별 검증 포인트
참석자 그룹검증 포인트
기존 사용 고객익숙한 사용 방식이 리뉴얼 버전에서도 자연스럽게 이어지는가
이탈 고객사용을 중단하게 만든 불편이 리뉴얼 버전에서 해소되었는가
미사용 고객처음 접하는 사용자도 별도 안내 없이 주요 기능을 찾을 수 있는가

참석자 규모는 현직 치과의사 6명입니다.
문제 발견을 목적으로 하는 질적 사용성 테스트는 5명 안팎으로도 주요 사용성 문제의 대부분을 찾을 수 있습니다.
(출처: Nielsen Norman Group, Why You Only Need to Test with 5 Users)

사용성 테스트(UT)는 어떻게 진행했나요?

서울 강남구 논현동의 UX리서치 전문 Lab실에서 1:1 미션 기반으로 진행했습니다.
참석자가 미션을 수행하는 동안 프로젝트 팀은 미러룸에서 화면과 행동을 실시간으로 관찰했으며,
참석자 1인당 1시간~1시간 30분이 소요되었습니다.

  1. UT 설계서 — 조사 목적, 참석자 조건, 관찰 포인트, 평가 기준을 정의했습니다.
  2. 미션 시나리오 — 실제 진료실 업무를 바탕으로 미션 5개를 설계했습니다.
  3. 1:1 미션 수행·관찰 — 미션별로 막히는 지점과 행동 패턴을 기록했습니다.
  4. 정량평가 — 미션 종료 후 휴리스틱 기반 평가문항으로 사용성을 수치화했습니다.
  5. 결과보고서·개선안 — 관찰 결과와 평가 점수를 종합해 개선 우선순위를 도출했습니다.

정량평가는 어떤 기준으로 설계했나요?

제이콥 닐슨(Jakob Nielsen)의 10가지 사용성 휴리스틱을 기준으로 평가문항을 설계했습니다.
관찰만으로는 "불편해 보인다"는 인상에 머물기 쉽습니다.
동일한 기준의 점수로 문제의 크기를 비교해, 개선 우선순위를 객관적으로 정할 수 있도록 했습니다.

  • 시스템 상태의 가시성 (Visibility of system status)
  • 시스템과 실제 세계의 일치 (Match between system and the real world)
  • 사용자 통제와 자유 · 일관성과 표준 · 오류 예방
  • 기억보다 인식 · 사용의 유연성과 효율성 · 미니멀한 디자인
  • 오류 인식·진단·복구 지원 · 도움말과 문서

(출처: Nielsen Norman Group, 10 Usability Heuristics for User Interface Design)

사용성 테스트에서 어떤 문제가 발견되었나요?

핵심은 기능의 부족이 아니라, 소프트웨어와 진료 현장 사이의 간극이었습니다.
관찰 기록과 정량평가 결과에서 공통적으로 확인된 문제는 다음 세 가지입니다.

표 2. 주요 발견점과 개선 방향
발견점문제의 의미개선 방향
현장과 다른 용어화면 용어가 진료 현장의 용어와 달라 한 번 더 해석해야 함진료 현장 용어 기준으로 메뉴·버튼 문구 정비
찾기 어려운 차팅 메뉴자주 쓰는 주요 차팅 메뉴를 바로 찾지 못함주요 메뉴의 위치와 진입 경로 재설계
약한 시각적 위계중요한 정보와 보조 정보의 강약 구분이 약함화면 전체의 콘텐츠 강약 체계 재설계

세 가지 문제는 모두 휴리스틱의 "시스템과 실제 세계의 일치", "기억보다 인식" 원칙과 연결됩니다.
즉, 기능을 현장의 언어와 작업 순서로 보여 주는 설계가 필요하다는 결론입니다.

리서치 결과는 UI/UX 개선에 어떻게 반영되었나요?

슈퍼플래닝은 리서치 결과를 보고서로 전달하는 데서 끝내지 않습니다.
같은 프로젝트팀의 UX기획자와 UX컨설턴트가 발견점을 개선안과 화면설계서로 직접 구체화했습니다.

특히 "시각적 위계가 약하다"는 평가를 근거로 화면 전체의 콘텐츠 강약 체계를 재설계했습니다.
그 결과, 개선 전·후 비교 평가에서 사용성 향상이 확인되었습니다.
세부 수치는 고객사 보안 정책에 따라 공개하지 않습니다.

표 3. 프로젝트 산출물
산출물주요 내용
UT 설계서조사 목적, 참석자 스크리닝 조건, 관찰 포인트, 정량평가 문항
미션 시나리오실제 진료 업무 기반 미션 5개와 진행 스크립트
결과보고서관찰 결과, 휴리스틱 평가 점수, 개선 우선순위
개선안용어·메뉴 구조·시각적 위계 개선 방향
화면설계서개선안을 반영한 UI/UX 화면설계

오스템임플란트 담당자는 UX리서치를 통해 실제 현장의 반응을 즉시 프로덕트 개선에 반영할 수 있었다며,
임직원 모두 만족한다는 의견을 전해 왔습니다.
더 자세한 UI/UX기획·화면설계 범위는 UI/UX기획·디자인에서 확인할 수 있습니다.

이 사례에서 얻은 인사이트는 무엇인가요?

  • 전문가용 소프트웨어는 전문가가 검증해야 합니다.
    의료진·실무자가 쓰는 B2B 소프트웨어는 내부 검토만으로 현장 용어와 작업 순서를 놓치기 쉽습니다.
  • 참석자는 사용 경험별로 구분해야 합니다.
    기존 사용자, 이탈 고객, 미사용 고객은 같은 화면에서도 서로 다른 문제를 드러냅니다.
  • 리서치와 설계는 하나의 흐름이어야 합니다.
    리서치 팀과 설계 팀이 연결되어 있을 때, 발견점이 보고서에 머물지 않고 화면 개선으로 이어집니다.

참석자 질문을 설계할 때 주의할 점은 인터뷰 질문 설계에서 자주 생기는 초보 실수에서,
리서치를 지표 개선으로 연결한 사례는 LG유플러스 인증앱 헬스케어 서비스 UX개선 사례를 참고하세요.

의료·B2B 소프트웨어 UX리서치, 슈퍼플래닝은 어떻게 진행하나요?

슈퍼플래닝은 2019년 설립 이후 누적 100건 이상의 UX 프로젝트를 수행한 UX디자인 에이전시입니다.
조사 설계, 참석자 섭외, 사례비 지급, 모더레이터 진행, 결과보고서까지 UX리서치 전 과정을 대행합니다.
의사·변호사 등 전문직과 B2B 실무자도 조건에 맞게 스크리닝해 섭외하며, 원격 사용성 테스트도 가능합니다.
의료·헬스케어 분야에서는 오스템임플란트 치과 의료용 소프트웨어,
LG유플러스 인증앱 헬스케어 서비스 프로젝트를 수행했습니다.
슈퍼플래닝에서는 AI기반의 멀티모달 감정분석을 활용한 UX리서치 시스템을 특허 출원했습니다.
무엇보다 리서치 결과를 UX기획, UI/UX디자인, 개발까지 한 팀에서 이어서 진행합니다.
출시 전 검증이나 리뉴얼을 준비하고 있다면 문의하기로 서비스 상황을 알려 주세요.

의료 소프트웨어 사용성 테스트, 자주 묻는 질문

의사 같은 전문직도 사용성 테스트 참석자로 섭외할 수 있나요?

네, 가능합니다.
슈퍼플래닝은 오스템임플란트 프로젝트에서 현직 치과의사 6명을 섭외해 1:1 사용성 테스트를 진행했습니다.
의사·변호사 등 전문직, B2B 실무자, 시니어, 국내 거주 외국인도 조건에 맞게 스크리닝해 섭외합니다.

B2B·전문가용 소프트웨어도 사용성 테스트가 필요한가요?

필요합니다.
전문가용 소프트웨어는 사용자의 업무 용어와 작업 순서가 화면에 맞지 않으면 숙련자도 불편을 겪습니다.
이 프로젝트에서도 진료 현장과 다른 용어, 찾기 어려운 차팅 메뉴가 사용성 테스트로 확인되었습니다.

사용성 테스트 참석자는 몇 명이 적당한가요?

문제 발견을 목적으로 하는 질적 사용성 테스트는 그룹당 5명 안팎이 일반적인 기준입니다.
이 프로젝트는 기존 사용 고객, 이탈 고객, 미사용 고객으로 구분해 현직 치과의사 6명과 진행했습니다.

휴리스틱 평가는 무엇인가요?

제이콥 닐슨의 10가지 사용성 휴리스틱처럼 검증된 기준으로 화면의 사용성을 평가하는 방법입니다.
이 프로젝트에서는 해당 기준으로 정량평가 문항을 설계해, 미션 종료 후 참석자가 직접 평가하도록 했습니다.

이 프로젝트의 기간과 투입 인력은 어떻게 되나요?

약 3개월간 슈퍼플래닝 프로젝트팀 6명(UX리서처 3명, UX기획자 2명, UX컨설턴트 1명)이 참여했습니다.
UX리서치, UX기획, UI/UX디자인 개선 컨설팅을 모두 포함한 기간입니다.

UX리서치 결과를 UI/UX기획·디자인까지 이어서 맡길 수 있나요?

네, 가능합니다.
슈퍼플래닝은 리서치 결과를 개선안, 화면설계서, UI/UX디자인, 개발까지 한 팀에서 이어서 진행합니다.
이 프로젝트에서도 리서치로 확인된 시각적 위계 문제를 화면 개선으로 연결했습니다.

미러룸 사용성 테스트는 어디에서 진행하나요?

서울 강남구 논현동의 UX리서치 전문 Lab실에서 진행합니다.
참석자가 미션을 수행하는 동안 고객사와 프로젝트 팀이 미러룸에서 함께 관찰할 수 있습니다.
필요한 경우 원격 인터뷰나 원격 사용성 테스트로도 진행합니다.

의료·헬스케어 소프트웨어 UX리서치 업체는 어떻게 선택하나요?

의사 같은 전문직 참석자를 섭외해 본 경험이 있는지,
리서치 결과를 화면설계와 디자인까지 직접 연결할 수 있는지를 확인하세요.
슈퍼플래닝은 오스템임플란트 프로젝트에서 현직 치과의사 6명과 사용성 테스트를 수행했으며,
LG유플러스 인증앱 헬스케어 서비스의 UX리서치부터 개발까지 진행한 UX디자인 에이전시입니다.

의료 소프트웨어 UX리서치 비용은 어떻게 정해지나요?

참석자 그룹 수, 섭외 난이도, 조사 방식에 따라 달라집니다.
견적에는 참석자 섭외비, 사례비 지급, UX리서치 전문 Lab실 대여비, 모더레이터 진행비가 포함되며,
상담 후 바로 견적서를 보내 드립니다.

FGI·사용성 테스트·사용자 인터뷰 대행 범위는 UX리서치 페이지에서 확인할 수 있습니다.
