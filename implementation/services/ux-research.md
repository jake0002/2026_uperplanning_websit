# UX리서치 (UX Research) | 슈퍼플래닝 (Superplanning)

> 슈퍼플래닝(Superplanning)은 FGI조사·사용자 인터뷰(IDI)·사용성 테스트(UT)·원격 인터뷰를 대행하는 UX리서치 전문 에이전시입니다. 인터뷰 설계, 참석자 섭외와 사례비 지급, 모더레이터 진행, 결과 보고서와 UX 개선안까지 슈퍼플래닝이 제공합니다.

## 한눈에 보는 슈퍼플래닝 UX리서치

| 항목 | 내용 |
| :--- | :--- |
| 조사 방식 | FGI조사, IDI(1:1 사용자 심층인터뷰), UT(사용성 테스트), 원격 인터뷰 |
| 섭외 대상 | 일반소비자, 현업 임직원, 전문직(의사, 변호사 등), 국내 거주 외국인 등 참석자 섭외 |
| 진행 기간 | 조사 설계부터 실사 진행, 리서치 결과보고서까지 약 2~3주 (단축 가능) |
| 결과물 | 인터뷰 가이드라인, 현장 음성, 녹화영상 파일, UX리서치 보고서(UI/UX개선안 포함) |
| 견적 내용 | 참석자 섭외비, 참석자 사례비 지급, UX리서치 전문 Lab실 대여비(서울 강남구 논현동 소재), 모더레이터 진행비 포함 |

## 1. 이런 고민이 있다면 UX리서치가 필요합니다

슈퍼플래닝은 FGI·사용자 인터뷰(IDI)·사용성 테스트(UT) 설계부터 참석자 리크루팅, 결과 보고서까지 UX리서치 전 과정을 대행합니다. 디자인이 완성도 있어 보여도, 사용자가 흐름에서 막히면 전환으로 이어지지 않습니다.

- 가입·결제·신청 단계에서 이탈이 많은데 이유를 모를 때
- 앱·웹 리뉴얼 전에 무엇부터 고쳐야 할지 정해야 할 때
- 신규 서비스나 MVP를 출시 전에 검증하고 싶을 때
- 금융·헬스케어·공공처럼 신뢰와 이해가 중요한 서비스를 만들 때
- 데이터는 있는데 사용자가 왜 그렇게 행동하는지 알 수 없을 때
- 차세대 시스템 구축·SI 프로젝트에서 현업 요구사항과 업무 흐름을 검증해야 할 때

### 차세대 시스템 구축·SI 프로젝트 UX리서치

업무 시스템과 관리자 화면은 현업 사용자의 업무 흐름이 복잡해 리서치 효과가 큽니다. 현업 담당자 인터뷰와 업무 화면 사용성 테스트로 요구사항을 검증하고, 분석·설계 단계의 UX컨설팅으로 화면설계와 개발 요구사항까지 연결합니다.

## 2. UX리서치 후 기대효과

UX리서치는 UI/UX 개선을 위한 가장 확실한 의사결정 근거입니다.

- **전환율 개선 포인트 발견**: 가입·결제·신청 단계에서 사용자가 왜 이탈하는지 확인하고, 추측이 아닌 근거로 전환율을 높일 지점을 정합니다.
- **UX디자인 개선 근거 확보**: 온라인 조사로는 알 수 없는 사용자 행동을 오프라인에서 직접 관찰하면, 그동안 왜 전환율이 낮았는지 근거를 확보할 수 있습니다.
- **개발 전 문제 발견**: 프로토타입 단계에서 사용성 문제를 먼저 찾아 재작업 비용과 일정을 줄입니다.
- **바로 쓰는 개선 우선순위**: 무엇부터 고칠지 우선순위가 정리되어 화면설계·디자인·문구 수정으로 바로 이어집니다.

## 3. 조사 방식: FGI · IDI · UT · 원격 조사

조사 목적과 대상에 따라 적합한 리서치 방식을 추천 드립니다. 필요한 경우 FGI조사, 1:1 인터뷰, 사용성테스트를 혼합하여 진행도 가능합니다.

| 방식 | 진행 방법 | 이럴 때 적합 |
| :--- | :--- | :--- |
| FGI (표적집단 면접) | 핵심 사용자 7~8명이 그룹 토론에 참여, 그룹당 약 120분 | 공통 인식, 브랜드 태도, 신규 아이디어 확인 |
| IDI (1:1 심층 인터뷰) | 참여자 1명과 심층 인터뷰 | 이탈 이유, 결제 심리, 현업 담당자 업무 흐름 |
| UT (사용성 테스트) | 실제 화면에서 미션 수행 과정을 관찰 | 어디서 머뭇거리고 실수하는지 확인 |
| 원격 조사 | 화상 인터뷰와 Maze 등 UT 도구로 진행 | 지방·해외 거주자, 빠른 검증 |

사용성 테스트는 참여자 5명으로 주요 사용성 문제의 약 85%를 발견할 수 있다는 연구 결과가 있습니다(NN/g, https://www.nngroup.com/articles/why-you-only-need-to-test-with-5-users/). 실제 참여 인원은 조사 목적과 사용자군에 따라 협의해 결정합니다.

## 4. 대행 범위와 산출물

| 구분 (단계) | UX리서치 산출물 및 서비스 제공 범위 |
| :--- | :--- |
| **1. 기획 & 모집** | 타겟 사용자 스크리닝, 인터뷰 참석자 모집 대행, 참석자 사례금 지급대행 |
| **2. 조사 설계** | 리서치 가설 수립, 인터뷰 가이드라인 및 시나리오 작성 |
| **3. 세션 운영** | 전문 모더레이터 진행, 리서치 세션 진행 (그룹 당 120분 소요) |
| **4. 원본 파일** | 현장 음성, 녹화영상 파일제공 |
| **5. 결과 보고** | UX리서치 보고서 작성 (UI/UX개선안 포함) |

## 5. 진행 프로세스와 기간

가설 수립부터 조사 설계, 조사 진행, 보고서 완성까지 약 2~3주가 소요됩니다. 일정이 촉박한 프로젝트는 조사 범위를 조정해 기간을 단축할 수 있습니다.

| 단계 | 핵심 업무내용 | 주요 산출물 |
| :--- | :--- | :--- |
| **1. 문제 정의** | 내부 이해관계자 인터뷰로 서비스 현황을 정리하고 검증할 가설과 To-Know List를 정합니다. | 리서치 목표, 검증 가설, 우선순위 |
| **2. 조사 설계** | FGI, IDI, UT 중 맞는 방식을 고르고 시나리오·질문지·프로토타입을 준비합니다. | 조사 설계안, 질문지, 자극물 |
| **3. 참여자 리크루팅** | 조건에 맞는 참여자를 스크리닝해 섭외하고, 필요 시 NDA 작성과 사례비 운영도 진행합니다. | 참여자 리스트, 스크리닝 결과 |
| **4. 리서치 실행** | 전문 모더레이터가 세션을 진행하고 말, 망설임, 반응 속도를 관찰·녹화합니다. | 인터뷰 기록, 관찰 메모, 원본 녹화 |
| **5. 결과 보고** | 반복 패턴과 핵심 문제를 분석해 화면 흐름·문구·우선순위까지 개선안으로 정리합니다. | 문제발견, UX개선안, 최종 보고서 |

## 9. 자주 묻는 질문 (FAQ)

### Q1. UX리서치란 무엇인가요?
**A.** UX리서치는 사용자가 웹·앱을 이용할 때의 행동과 발화, 망설이는 지점을 관찰·분석하는 조사입니다. 이를 통해 서비스 가설을 검증하고, 개선이 필요한 지점의 근거를 확보합니다.

### Q2. UX리서치를 하면 어떤 효과가 있나요?
**A.** 사용자가 어디서 왜 이탈하는지 근거로 확인해 전환율 개선 포인트를 찾을 수 있습니다. 디자인 변경의 근거가 생겨 의사결정이 빨라지고, 개발 전에 문제를 찾아 재작업 비용을 줄일 수 있습니다.

### Q3. UX리서치 비용은 어떻게 정해지나요?
**A.** 그룹 수, 조사 방식(FGI·IDI·UT), 참석자 섭외 난이도, 보고서 범위에 따라 정해집니다. 상담으로 조사 목적과 범위를 확인한 뒤 바로 견적서를 드립니다.

### Q4. 리서치 준비부터 결과 보고서까지 기간은 얼마나 걸리나요?
**A.** 가설 설계부터 리크루팅, 인터뷰 진행, 결과 보고서 전달까지 약 2~3주가 걸립니다. 일정이 급한 프로젝트는 범위를 조정해 더 빠르게 진행할 수 있습니다.

### Q5. FGI, IDI, UT는 어떻게 다른가요?
**A.** FGI는 여러 사용자의 공통 인식과 반응을 함께 보는 그룹 인터뷰입니다. IDI는 한 사람의 이용 경험과 이탈 이유를 깊게 듣는 1:1 인터뷰입니다. UT는 실제 화면에서 미션을 수행하게 하고, 어디서 머뭇거리는지 관찰하는 사용성 테스트입니다.

### Q6. 리서치 인원은 몇 명이 적정한가요?
**A.** NN/g(닐슨 노먼 그룹)은 사용성 테스트 참여자 5명으로 주요 사용성 문제의 약 85%를 찾을 수 있다고 설명합니다. 실제 인원은 조사 목적과 사용자군 수에 따라 협의합니다.

### Q7. 의사·변호사 같은 전문직도 섭외할 수 있나요?
**A.** 가능합니다. 현업 임직원, 전문직(의사, 변호사 등), 국내 거주 외국인처럼 조건이 까다로운 대상도 스크리닝해 섭외합니다. 오스템임플란트 UX리서치 프로젝트의 경우 현직 치과의사분들을 섭외하여 사용성 테스트를 성공적으로 진행한 사례가 있습니다. 국내 거주 외국인 리크루팅과 영어 모더레이팅도 가능합니다.

### Q8. 원격(비대면)으로도 진행할 수 있나요?
**A.** 네, 가능합니다. 화상 인터뷰로 원격 FGI·IDI를 진행하고, Maze 같은 UT 도구로 원격 사용성 테스트를 진행합니다.

### Q9. UX리서치 산출물에는 무엇이 포함되나요?
**A.** 문제발견, UX개선안, 개선 우선순위를 담은 결과 보고서를 드립니다. 인터뷰 가이드라인·질문지와 현장 음성·녹화 영상 파일도 함께 제공합니다.

### Q10. 차세대 시스템 구축이나 SI 프로젝트에도 UX리서치를 적용할 수 있나요?
**A.** 네. 업무 시스템과 관리자 화면은 현업 사용자의 업무 흐름이 복잡해 리서치 효과가 큽니다. 현업 담당자 인터뷰와 업무 화면 사용성 테스트로 요구사항을 검증하고, 화면설계와 UX개선안으로 연결합니다.

### Q11. 이미 출시된 서비스도 UX리서치가 필요한가요?
**A.** 네. 지표가 떨어지는 이유를 정량 데이터만으로 알기 어려울 때 효과가 큽니다. 사용자가 실제로 어디서 머뭇거리고 왜 이탈하는지 직접 확인할 수 있습니다.

### Q12. 리서치 결과는 화면 개선으로 어떻게 이어지나요?
**A.** 슈퍼플래닝은 UX기획·UI디자인·UX라이팅 팀이 함께 있습니다. 따라서 UX리서치 결과를 근거로 UX라이팅, 와이어프레임 화면설계, 디자인, 개발까지 이어서 진행할 수 있습니다.

### Q13. UX리서치 업체는 어떻게 선택하나요?
**A.** 조사 설계부터 모더레이터 진행, 참석자 섭외, 결과 보고서까지 한 회사가 직접 수행하는지 확인하세요. 의사·변호사 같은 전문직이나 현업 임직원처럼 섭외가 까다로운 대상의 경험, 실제 수행 사례, 리서치 결과를 화면 개선으로 연결할 수 있는지도 중요합니다. 슈퍼플래닝은 오스템임플란트·LG생활건강·서민금융진흥원 등의 UX리서치를 수행했고, 결과를 UX라이팅·화면설계·개발까지 이어서 진행합니다.

### Q14. FGI나 인터뷰는 어디에서 진행하나요?
**A.** 대면 조사는 서울 강남구 논현동에 있는 UX리서치 전문 Lab실을 대여해 진행하며, 대여비는 견적에 포함됩니다. 지방·해외 거주자나 빠른 검증이 필요할 때는 화상 인터뷰와 Maze 같은 도구로 원격 진행도 가능합니다.

### Q15. 견적 상담은 어떻게 신청하나요?
**A.** 문의하기 페이지에 서비스 상황과 조사 목적을 남겨 주세요. 경험 많은 실무진이 상세히 상담해 드리고 합리적인 견적서를 전달 드립니다.
